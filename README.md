# 💡 Tech Workforce 360° – Power BI Dashboard

🎯 A dynamic Power BI project analyzing workforce trends in the IT sector, with a focus on skill distribution, attrition, and upskilling impact.

## 📊 Dashboard Objectives
- Visualize tech skillsets across departments and roles
- Track attrition patterns based on skill, experience, and performance
- Evaluate upskilling program effectiveness on retention
- Identify high-risk teams due to outdated skills
- Forecast future skill demand in the organization

## 🔧 Tools Used
- Power BI
- Microsoft Excel
- DAX
- Power Query
- Data Modeling

## 📐 Key Visuals
- ✅ Tree Map – Skill Distribution
- 📉 Line Chart – Monthly Attrition & Training Trends
- 🔄 Sankey Chart – Upskilling → Retention Flow
- 🔍 Scatter Plot – Experience vs Performance vs Attrition
- 📊 Bar Charts – Attrition by Role / Skill / Department

## 📌 Filters / Slicers
- Location
- Department
- Skill
- Experience
- Training Status

## 💼 Use Case
Designed for IT organizations to understand their workforce capabilities, improve retention strategies, and guide investments in skill development—especially relevant in today’s rapidly evolving tech landscape.
